# SteamVR Battery Indicator

Оверлей для SteamVR, который показывает заряд шлема прямо на руке (на контроллере).
Оверлей крепится к контроллеру как `TrackedDeviceRelative`, поэтому он висит в воздухе
рядом с рукой и всегда виден в шлеме.

Написано на **C++** без внешних зависимостей: библиотека OpenVR подгружается во время
работы (`dlopen` / `LoadLibrary`), текстура индикатора рисуется на CPU и отдаётся в
`SetOverlayRaw`. Собирается одним файлом через `g++` или CMake.

## Что показывает

- Большая батарейка с процентом заряда шлема.
- Молния (с анимацией), когда шлем заряжается.
- Цвет по уровню заряда: зелёный (>=50%), жёлтый (20–49%), красный (<20%), серый (нет данных).

## Требования

- **Windows:** ничего устанавливать не нужно — в репозитории лежит готовый
  `dist\steamvr_battery_indicator.exe`. Просто запустите `start.bat`.
- **Linux / macOS:** компилятор C++17 (`g++` или `clang++`).
- Запущенный SteamVR на этой же машине.

Никаких библиотек устанавливать не нужно — OpenVR подгружается во время работы.

## Сборка (нужна только если нет готового бинарника)

```bash
# вариант 1: make
make

# вариант 2: CMake
cmake -B build && cmake --build build

# вариант 3: напрямую
g++ -std=c++17 -O2 -Isrc src/main.cpp -o steamvr_battery_indicator -ldl
```

После сборки в корне появится исполняемый файл `steamvr_battery_indicator`
(на Windows — `steamvr_battery_indicator.exe`).

## Быстрый запуск

- **Windows:** двойной клик по `start.bat`. Он запускает готовый
  `dist\steamvr_battery_indicator.exe` — компилятор не нужен. Если готового
  файла нет, лаунчер попробует собрать из исходников, а если компилятора тоже
  нет — покажет подсказку.
- **Linux / macOS:** двойной клик по `start.sh` (или `./start.sh`) — соберёт при
  необходимости и запустит.
- **Вручную:** `./steamvr_battery_indicator`

Перед запуском должен быть запущен SteamVR. Выход — `Ctrl+C`.

Скрипты-лаунчеры принимают те же параметры, что и программа:
`./start.sh --hand left`, `start.bat --source right`.

## Лог-файл

Программа пишет текстовый лог рядом с собой — `steamvr_battery_indicator.log`.
Туда попадают запуск, загрузка OpenVR, изменения заряда и ошибки. Это удобно,
если что-то не работает: файл остаётся после закрытия окна.

- Свой путь: `--log C:\path\to\file.log`
- Отключить лог: `--no-log`

Строки лога также дублируются в консоль.

## Параметры

```bash
./steamvr_battery_indicator --hand left       # на левой руке
./steamvr_battery_indicator --source right    # заряд контроллера, а не шлема
./steamvr_battery_indicator --anchor hmd      # закрепить на шлеме, а не на руке
./steamvr_battery_indicator --list            # какие устройства видны и их заряд
./steamvr_battery_indicator --preview p.png   # отрисовать один кадр без SteamVR
```

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `--source` | `hmd` | Чей заряд показывать: `hmd`, `left`, `right` |
| `--anchor` | `hand` | К чему крепить оверлей: `hand` или `hmd` |
| `--hand` | `right` | Контроллер при `--anchor hand` |
| `--width` | `0.14` | Ширина оверлея в метрах |
| `--offset` | `0 0.055 0.075` | Смещение от якоря (X Y Z, метры) |
| `--rotate` | `180 -18 0` | Поворот относительно якоря (YAW PITCH ROLL, градусы) |
| `--fps` | `15` | Частота обновления анимации |
| `--poll-interval` | `1.0` | Как часто опрашивать заряд, секунды |
| `--preview PATH` | — | Отрисовать один кадр в PNG и выйти |
| `--list` | — | Показать устройства и заряд, выйти |
| `--log PATH` | рядом с exe | Куда писать текстовый лог |
| `--no-log` | — | Не писать лог-файл |

## Если OpenVR не находится

Программа ищет библиотеку OpenVR сама:

- рядом с самой программой;
- на Windows — в реестре (`HKCU`/`HKLM\Software\Valve\Steam`, `...\Valve\OpenVR`)
  и во всех библиотеках Steam (включая другие диски через `libraryfolders.vdf`);
- на Linux — в стандартных папках Steam.

Если SteamVR стоит нестандартно, укажите путь явно:

```bat
set STEAMVR_OPENVR_PATH=E:\Steam\steamapps\common\SteamVR\bin\win64
dist\steamvr_battery_indicator.exe
```

```bash
STEAMVR_OPENVR_PATH=/path/to/libopenvr_api.so ./steamvr_battery_indicator
```

Все проверенные пути пишутся в лог-файл, так что видно, где программа искала.

## Тесты

```bash
g++ -std=c++17 -Isrc tests/test_logic.cpp -o /tmp/test_logic -ldl && /tmp/test_logic
```

Проверяются матрица трансформации, отрисовка текстуры/PNG, чтение заряда и выбор
устройства по роли (через подставную таблицу функций `IVRSystem`), а также полный
путь запуска оверлея (через подставную таблицу `IVROverlay`).

## Если программа закрывается сразу после запуска

Смотрите `steamvr_battery_indicator.log`: теперь туда пишутся шаги запуска
(`Creating overlay...`, `Overlay created...`, `First frame uploaded.`), а если
программа аварийно падает — строка `CRASH: unhandled exception ...` с кодом и
адресом. Это позволяет понять, на каком вызове всё ломается.

## Структура

```
src/openvr_capi.h     официальный C-заголовок OpenVR (Valve, BSD-3)
src/runtime.h         загрузка библиотеки OpenVR во время работы
src/log.h             простой текстовый лог-файл
src/image.h           CPU-растр: примитивы + запись PNG без зависимостей
src/indicator.h       отрисовка индикатора (батарейка, молния, текст)
src/font8x8.h         растровый шрифт 8x8 (public domain)
src/main.cpp          параметры, чтение заряда, оверлей, главный цикл
tests/test_logic.cpp  модульные тесты логики
dist/                 готовый steamvr_battery_indicator.exe (Windows, x64)
```

## Заметки

- Проценты и флаг зарядки берутся из OpenVR-свойств устройства
  (`Prop_DeviceBatteryPercentage_Float`, `Prop_DeviceIsCharging_Bool`).
  Шлем сообщает эти данные не всегда — тогда индикатор покажет `--`.
- Текстура оверлея 640x256, формат BGRA, обновляется только при изменении
  состояния (и постоянно, пока идёт зарядка, ради анимации молнии).
- Точное положение оверлея зависит от модели контроллера — при необходимости
  подстройте `--offset` и `--rotate`.
